# StudyMate — אפליקציית סטודנטים סטטית

## הפעלה
פתחו `index.html` בדפדפן. לפריסה ב-Netlify: גררו את התיקייה `studymate-student-app` ל-https://app.netlify.com/drop . אין צורך בבנייה או בשרת.

## יכולות
- העלאת PDF טקסטואלי, TXT או MD, או הדבקת טקסט.
- ספריית סיכומים בדפדפן (localStorage).
- תקציר אוטומטי בסיסי המבוסס על בחירת משפטים ומילות מפתח — לא AI.
- יצירת שאלות השלמת מושג מתוך משפטי המקור, בדיקת תשובות וציון.
- היסטוריית מבחנים וסטטיסטיקות.
- תצוגה רספונסיבית בעברית.

## מגבלות
- **ללא AI וללא שרת**: לא מדובר בסיכום סמנטי או ביצירת שאלות חכמות. יש לבדוק את איכות התוצרים.
- קריאת PDF משתמשת ב-PDF.js דרך CDN ולכן דורשת חיבור לאינטרנט. PDF סרוק אינו נתמך.
- נתונים נשמרים רק בדפדפן ובמכשיר הנוכחי; ניקוי נתוני הדפדפן ימחק אותם. אין סנכרון או גיבוי.
- האחסון מוגבל; קבצים גדולים עשויים להיכשל.
- אין להעלות מידע אישי רגיש למחשב משותף.
